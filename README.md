# Java Employee Management System

A simple console-based Employee Management System developed in Java.

## 📌 About the Project

This project demonstrates basic Java concepts such as:

- Classes and Objects
- Instance Variables
- Encapsulation
- Getters and Setters
- User Input using Scanner
- Basic Employee Information Management

## ✨ Features

- Add employee details
- Store employee ID
- Store employee name
- Store department
- Store designation
- Store monthly salary
- Display employee details

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
